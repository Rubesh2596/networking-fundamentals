# 02 Networking Models

This module introduces the mental tools that help beginners understand how network communication is organized.

## Why this module matters

Network engineers and developers often talk about layers because communication is not just one big action. It is a sequence of tasks performed by different parts of the system.

This module teaches you the two most useful models:

- the OSI model, which is conceptual and easy to learn
- the TCP/IP model, which matches real Internet behavior more closely

Without this lesson, many networking topics feel like a stack of jargon. With it, the structure becomes much easier to understand.

## Beginner-friendly roadmap

1. Start with [osi-model.md](osi-model.md)
2. Compare the two models in [osi-vs-tcp-ip.md](osi-vs-tcp-ip.md)
3. Learn the practical model in [tcp-ip-model.md](tcp-ip-model.md)
4. Study how data is wrapped and unpacked in [encapsulation-and-decapsulation.md](encapsulation-and-decapsulation.md)
5. Review practice questions in [practice-questions.md](practice-questions.md)

## One sentence to remember

The OSI model helps you learn networking in layers, and the TCP/IP model helps you understand how the real Internet works.
