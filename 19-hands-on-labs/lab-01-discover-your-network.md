# Lab 01: Discover your local network

## Difficulty
Beginner

## Estimated completion time
15 minutes

## Learning objectives
- Inspect the local interface
- Identify the IP address and gateway
- Understand how a device joins the network

## Required tools
- Terminal
- `ip` or `ipconfig`

## Steps
1. Run `ip addr` or `ipconfig /all`.
2. Note the interface name, IPv4 address, subnet mask, and default gateway.
3. Compare the result to the local network.

## Commands
```bash
ip addr
# or
ipconfig /all
```

## Questions
1. What is your local address?
2. What gateway is configured?
3. Is the address private or public?
