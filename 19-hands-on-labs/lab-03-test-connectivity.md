# Lab 03: Test connectivity

## Difficulty
Beginner

## Estimated completion time
20 minutes

## Learning objectives
- Verify local and remote reachability
- Use `ping` and `curl`
- Distinguish network failure from application failure

## Commands
```bash
ping -c 3 8.8.8.8
curl -I https://example.com
```

## Questions
1. Did the host respond?
2. Did the web request succeed?
3. What does a timeout suggest?
