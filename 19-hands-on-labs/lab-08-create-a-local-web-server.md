# Lab 08: Create a local web server

## Difficulty
Beginner

## Estimated completion time
20 minutes

## Learning objectives
- Run a web server locally
- Observe HTTP requests and responses
- Connect application behavior with networking

## Commands
```bash
python3 -m http.server 8000
curl http://127.0.0.1:8000
```

## Questions
1. What local address did the server bind to?
2. Did the request use HTTP or HTTPS?
3. What is the difference between `localhost` and `0.0.0.0`?
