# Lab 07: Capture authorized network traffic

## Difficulty
Intermediate

## Estimated completion time
30 minutes

## Learning objectives
- Use packet capture tools safely
- Inspect DNS or HTTP traffic
- Understand what packets reveal

## Commands
```bash
sudo tcpdump -i any -n
```

## Safety note
Only capture traffic on a lab or personal network you control.

## Questions
1. What protocol is visible in the traffic?
2. Can you identify addresses and ports?
3. What is the relationship to the OSI model?
