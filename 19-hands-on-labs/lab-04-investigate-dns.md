# Lab 04: Investigate DNS

## Difficulty
Beginner

## Estimated completion time
20 minutes

## Learning objectives
- Compare name resolution with IP reachability
- Query DNS records
- Understand why a hostname may fail even when IP connectivity is healthy

## Commands
```bash
dig example.com
nslookup example.com
```

## Questions
1. Did DNS answer successfully?
2. Did the IP address resolve as expected?
3. What if `ping` works but `curl` does not?
