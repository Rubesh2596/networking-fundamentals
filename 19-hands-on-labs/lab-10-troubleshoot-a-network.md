# Lab 10: Troubleshoot a network

## Difficulty
Intermediate

## Estimated completion time
30 minutes

## Learning objectives
- Use a structured troubleshooting path
- Separate physical, IP, DNS, and service issues
- Record findings and verify fixes

## Commands
```bash
ping -c 3 8.8.8.8
traceroute example.com
nslookup example.com
```

## Questions
1. Did connectivity fail at the local network, DNS, or application layer?
2. What evidence supports each conclusion?
3. What command would you run next?
