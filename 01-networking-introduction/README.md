# 01 Networking Introduction

This module is the beginner-friendly starting point for networking. It explains what a network is, why devices need to communicate, and what the basic building blocks look like in real life.

## Why this module matters

If you are new to networking, the hardest part is usually not the commands. It is the vocabulary and the mental model.

This module helps you answer questions like:

- what is a network?
- why do computers talk to each other?
- what are LANs, WANs, and Wi-Fi networks?
- what devices are involved in a basic network?
- how does one computer send data to another?

## Example scenario: one laptop sends a file to another laptop on the same Wi-Fi network

A laptop wants to send a file to another laptop connected to the same Wi-Fi network.

- The sender creates the file and prepares it for transmission.
- The file is broken into smaller pieces so it can be sent over the network.
- The device checks whether the destination is on the same local network.
- The sender uses the local network path and the receiving device's local address.
- The Wi-Fi access point and local switch route the traffic locally.
- The receiving laptop accepts the data and reassembles it.

This example is a great way to understand that local networking is often simpler than Internet networking, even though both use the same general concepts.
