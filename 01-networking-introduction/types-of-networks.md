# Types of Networks

## Learning objectives

After this lesson, you should be able to:

- explain the major types of networks
- describe the difference between a LAN and a WAN
- understand what a home, office, and data center network looks like
- recognize that the Internet is a huge network of networks

## 1. Why there are different network types

Not all networks are the same size or purpose.

A network can be:

- small and local
- large and spread across many cities
- wireless or wired
- private to one company or public to everyone

We classify networks by their size, purpose, and relationship to other networks.

## 2. LAN: Local Area Network

A Local Area Network (LAN) is a small network in one physical place.

Examples:

- a home Wi-Fi network
- a classroom network
- a small office network
- a server room in one building

A LAN usually has:

- a router
- a switch
- laptops, phones, and printers
- one shared local connection

A LAN is usually fast and close by.

### Example

```text
[ Laptop ] ---- [ Switch ] ---- [ Router ] ---- Internet
     |                                    |
   [ Printer ]                         [ ISP ]
```

## 3. WAN: Wide Area Network

A Wide Area Network (WAN) is a network spread over a larger area, often across cities, countries, or continents.

Examples:

- the Internet itself
- a company's branch office network connected to headquarters
- a national network used by a telecom provider

A WAN usually connects different LANs together.

### Simple idea

A LAN is like a neighborhood.
A WAN is like a road system connecting multiple neighborhoods across a region.

## 4. WLAN: Wireless Local Area Network

A Wireless Local Area Network (WLAN) is a LAN that uses wireless technology such as Wi-Fi.

Examples:

- your home Wi-Fi
- coffee shop Wi-Fi
- office wireless coverage

A WLAN still functions like a LAN, but the connection is wireless instead of wired.

## 5. PAN: Personal Area Network

A Personal Area Network (PAN) is a very small network around one person.

Examples:

- Bluetooth headphones connected to a phone
- smartwatch connected to a phone
- wireless keyboard and mouse

PANs are usually short-range and personal.

## 6. MAN: Metropolitan Area Network

A Metropolitan Area Network (MAN) covers a city or a large campus area.

Examples:

- a city network connecting municipal offices
- a university network connecting buildings in one city
- a private network spanning multiple campuses

A MAN is larger than a LAN but smaller than a national or global network.

## 7. The Internet

The Internet is the largest public network of networks.

It connects:

- home networks
- corporate networks
- data centers
- cloud providers
- schools and governments

It is not one single machine or one single company. It is a massive set of connected networks working together.

## 8. Home, office, enterprise, and data-center networks

### Home network

A home network is usually small and simple.

Typical devices:

- laptop
- smartphone
- smart TV
- router
- printer

### Office network

An office network may include:

- desktops and laptops
- shared storage
- printers
- switches
- Wi-Fi access points
- security devices

### Enterprise network

An enterprise network is larger and more complex.

It may include:

- many buildings
- multiple departments
- firewalls and access control
- VPN connections
- site-to-site links
- central monitoring and security systems

### Data-center network

A data center network connects servers, storage, load balancers, and network equipment in a highly structured environment.

It handles huge volumes of traffic and usually includes redundancy and high availability.

## 9. Peer-to-peer vs client-server

### Peer-to-peer (P2P)

In a peer-to-peer network, devices communicate directly with each other.

Example:

- two laptops connected on the same Wi-Fi network sharing files directly

### Client-server

In a client-server model, one device provides a service and other devices request it.

Example:

- your browser is a client
- a web server is the server

Most modern networks use client-server communication heavily.

## 10. Real-life comparison

Think of network types like this:

- PAN = one person's personal zone
- LAN = one building or one home
- WLAN = same idea but wireless
- MAN = city-scale network
- WAN = broader regional or global connection
- Internet = the worldwide set of networks

## 11. What beginners often confuse

### Confusing LAN with WAN

A LAN is local and usually close together.
A WAN is wide and often uses long-distance links.

### Confusing Wi-Fi with the Internet

Wi-Fi is a local wireless technology.
The Internet is the global network beyond the local network.

### Assuming the Internet is only one network

It is not. It is many networks connected together.

## 14. Summary

Networks come in different sizes and shapes. LANs are local, MANs cover a city, WANs cover larger areas, and the Internet is the global collection of all these networks working together. Understanding these differences helps you understand how modern communication works.
